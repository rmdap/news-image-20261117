Entry for the make.fun bounty **"Sum up 17 November's world news in one image"**
(https://make.fun/bounty/news-image-20261117).

A front-page-style image summarising the day's world news: the U.S. strikes
on Iran and Iran's retaliation in the Gulf lead the page, followed by the
Kerch Bridge attack, the Trump–Xi–Putin summit in Shenzhen, the U.S. losing
measles-free status, Mongolia's president resigning, the marches across
France, the Siberian plane crash, Moldova's airspace closure, Japan
scrambling jets, and Britain's sanctions on Israeli firms. All events
happened or were first reported on Tuesday, 17 November 2026.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024, ~136 KB). Python 3.13, standard
library only — the program simply copies the bundled `entry.png`.
